# Автоматический переводчик модов RimWorld (Аддон для RimTrans)

Скрипт на Python и готовый `.exe` файл для автоматического перевода строк модов игры RimWorld на русский язык через Google Переводчик (используя библиотеку `deep-translator`).

> 🔴 **Важно:** На данный момент скрипт настроен на перевод **строго с английского языка на русский**. Моды на других языках (китайский, немецкий и т.д.) корректно переводиться не будут.

> ⚠️ **Примечание:** Этот скрипт является аддоном и работает в связке с оригинальной программой **RimTrans**. Он избавляет от необходимости переводить выгруженный файл вручную через браузер.

## 📥 Что нужно для работы:
1. Скачайте оригинальную программу **RimTrans** (которая вытаскивает текст из модов) с её официального репозитория: [RimWorld-zh/RimTrans](https://github.com/RimWorld-zh/RimTrans)
2. Скачайте мой готовый файл `autotranslatorRimWorld.exe` из раздела **Releases** (справа на этой странице).

## 🛠 Инструкция по шагам:
1. Запустите *RimTrans* и выгрузите текст из нужного мода RimWorld.
2. Полученный файл со строками переименуйте в `translations.csv`.
3. Положите файл `translations.csv` и мой `autotranslatorRimWorld.exe` **в одну папку** (например, создайте новую папку на Рабочем столе).
4. Запустите `autotranslatorRimWorld.exe` двойным кликом. Скрипт автоматически переведет все строки по цепочке через Google и сохранит готовый результат `translations_ready.csv` в этой же папке!

---
*Для разработчиков: Если вы хотите запустить проект из исходного кода, вам понадобятся Python 3 и библиотека `pip install deep_translator`.*
